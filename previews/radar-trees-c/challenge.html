HarnessVLN

  1. Challenge

    看见目标、提出动作和真正完成子目标并不等价

  2. Insight · 解释线索

    把证据、进度与执行结果统一管理，而非仅增强语义规划

  3. Approach

    规划提案 → 来源/几何/进度检查 → 工具执行 → 状态更新

  4. Evidence · 原文指定段落

    派发前检查观测来源、几何及子目标；停止请求另验语义、几何和进度。

  5. Open question · 待判别

    同一模型与预算下，停止验证改善了成功率还是仅改变拒停及额外观察次数？

证据范围与限制arXiv 2609.15195v3

实际核读：§3.1–3.3；§4.1–4.4 and Tables 2–4；Appendix 1.1–1.2；§2 and selected References

未核：未逐图视觉核验；未核全部补充内容；代码未读/未运行

跨论文结果受backbone和子集影响；未独立复现实验。

NavHarness

  1. Challenge

    旧搜索记录可能不完整或与新观测冲突

  2. Insight · 解释线索

    传递可追溯搜索证据，而非让旧判断自动成为事实

  3. Approach

    新会话读取记录 → 搜索/修正 → 检验结果 → 交接/跨run整理

  4. Evidence · 原文指定段落

    恢复保留剩余任务预算；交接区分已搜索和有证据排除，原任务记录不可由后续会话覆盖。

  5. Open question · 待判别

    在相同预算下加入可控环境变化，证据修订是否优于等长普通总结？

证据范围与限制arXiv 2609.34276v1

实际核读：§2–3.5；§4.1；Appendix B.3, C.1；Appendix D.4, E.1–E.9

未核：未逐图核验；未完整审查全部案例；代码未读/未运行

有限静态序列不证明真实终身运行或动态环境适应。

AgenticNav

  1. Challenge

    固定waypoint候选限制动作，堆历史使上下文冗余

  2. Insight · 解释线索

    让模型按需索取数值/视觉证据，几何计算留在工具

  3. Approach

    RGB目标像素 → 按需深度 → 几何检查 → 执行/选择性回看

  4. Evidence · 原文指定段落

    像素反投影后检查障碍；记忆限当前episode，每步重建有界上下文。

  5. Open question · 待判别

    等token和工具调用预算下，理由历史、进度记录与证据索引哪种更抗错误传播？

证据范围与限制arXiv 2606.10577v3 (2026-10-02)

实际核读：§II–III-D；§IV-A and Tables I–III；§V excerpt

未核：未完整核真实机器人实验；未逐图核验；代码未读/未运行

早期v1也曾查看，但本核心以v3为准；未做完整版本diff。

Qwen-RobotNav

  1. Challenge

    不同任务对历史长度和近期细节的需求不同

  2. Insight · 解释线索

    把上下文策略做成推理时可调接口

  3. Approach

    分配视觉token → 编码历史/视角 → 预测waypoint轨迹

  4. Evidence · 原文指定段落

    按时间与相机权重分配有上下限的视觉token；作者明确称其启发式。

  5. Open question · 待判别

    固定总预算时，按当前不确定性分配上下文是否优于固定时间衰减？

证据范围与限制arXiv 2606.18112v3

实际核读：§2.1–2.2, Algorithm 1；§5.5, Fig.15 caption and associated text

未核：未完整审训练数据；未读取图像像素或全部曲线；代码未读/未运行

此处读的是正文与图注文本，不声称独立量取曲线。

HoloAgent-0

  1. Challenge

    物理技能会部分失败，反馈不完整且有延迟

  2. Insight · 解释线索

    动作接口同时承载预期效果、进度和可恢复性

  3. Approach

    检索空间状态 → 技能图调度 → 状态反馈 → 监控/重规划

  4. Evidence · 原文指定段落

    技能返回结构化状态；新观测、物体操作结果或用户纠正触发局部记忆更新。

  5. Open question · 待判别

    固定导航后端时，结构化失败反馈是否比仅success/failure更能减少错误恢复？

证据范围与限制arXiv 2606.23565v1

实际核读：§2–3.1；§4.5；§5.1–5.2

未核：未完整核空间建图指标；未观看视频；代码未读/未运行

异构技能展示不直接证明持续导航或全部机器人能力稳定有效。

IVLN

  1. Challenge

    跨任务经验保留；长程指标与oracle隔离

  2. Insight · 解释线索

    把“记忆保留周期”和“oracle观察来源”拆成独立开关；用同一已训练模型切换记忆，比跨模型总分更能定位记忆贡献

  3. Approach

    RGB-D→占据/13类语义地图→自中心裁剪→CNN→CMA动作；另测跨episode隐状态/历史

  4. Evidence · 原文指定段落

    每episode后 oracle纠偏并带至下一起点；agent沿途被动观察

  5. Open question · 待判别

    同训练预算、同DAgger配置下，结构记忆优势还剩多少？；禁用纠偏阶段的被动观察后，后续收益是否保留？

实际核读：摘要；§1–2相关段；§3 tour/数据/指标；§4.1 TourHAMT段与§4.2；§5表2–4及分析；§6限制与未来工作

未核：附录A–C未系统读；无代码审计、数据下载或实验复现；图主要读取图注，未做逐像素图形核验

GOAT

  1. Challenge

    同类实例消歧；记忆收益与探索阶段耦合；本体执行差异

  2. Insight · 解释线索

    把“记住了目标位置”与“探索后匹配策略变了”拆开测；同时记录感知、检索、规划、执行四级失败，避免把总SR归因给单一记忆模块

  3. Approach

    RGB-D/pose→实例分割与语义图+多视角实例记忆→CLIP/SuperGlue匹配或frontier→FMM/本体控制器

  4. Evidence · 原文指定段落

    探索时阈值匹配，探索后取最高分；Spot与Stretch采用不同低层执行

  5. Open question · 待判别

    冻结goal matcher后，记忆还能带来多少效率提升？；移位对象、同类相邻对象会造成错误实例合并吗？

实际核读：§1相关段；§2.1–2.2任务/主实验及表1、图3图注；§2.3社会导航段；§3讨论目标匹配与检测局限；§4.1–4.2方法/协议；§5.1首段与匹配表局部

未核：未系统阅读全文参考文献；未观看视频；未审计代码；补充表未逐格验证；未逐页核对RSS版与v1差异

不能把15类实机评测解释为任意开放词汇实证；也不能把小规模动态人实验解释为普遍动态场景稳健性 v1 §4.1 与§5.1出现不同匹配阈值；本次不把任一组当成可复现默认值，需对照发布代码/最终版

GOAT-Bench

  1. Challenge

    可复现长期多模态协议；记忆利用因果诊断；目标输入鲁棒性

  2. Insight · 解释线索

    至少联合报告SR/SPL、目标模态、子任务序号和是否先前见过目标；单个总分会把识别能力与路线复用混在一起

  3. Approach

    比较modular实例地图、按模态skill chain、跨子任务GRU隐状态monolithic

  4. Evidence · 原文指定段落

    Stretch/Habitat，RGB-D+GPS/Compass；500动作/子目标，1m+STOP；三split环境均未见

  5. Open question · 待判别

    清空、打乱、过期记忆分别影响什么失败环节？；固定视觉与goal encoder后，显式/隐式记忆差异是否仍在？

证据范围与限制arXiv v1, 2024-04-09

实际核读：摘要；§1–2；§3；§4数据/生成流程与split相关段；§5；§6表2；§7.1–7.4；§8；附录C只零散段

未核：附录A–D未系统全读；图4–7主要核图注与正文结果而非逐像素读图；无训练复现或代码核验

RNN基线失败不等于长期上下文路线被否定；goal扰动不等于机器人视觉观测或位姿噪声鲁棒性

VLN-CE

  1. Challenge

    上层决策与真实执行接口；观测覆盖；评测环境先验

  2. Insight · 解释线索

    比较两个planner前先固定它们究竟得到哪种拓扑、定位与低层控制帮助；否则harness差异本身就可能解释成绩

  3. Approach

    RGB/深度ResNet特征+语言编码→Seq2Seq或双GRU跨模态注意力→低层动作

  4. Evidence · 原文指定段落

    不供位置/朝向；前进0.25m、转15°、STOP；无图拓扑及短程oracle

  5. Open question · 待判别

    同一高层轨迹经真实可失败控制器执行后，损失出现在哪一层？；增加观测覆盖与增加语言推理能力，哪个更能修复失败？

ObjectNav Revisited

  2. Insight · 解释线索

    让harness显式记录STOP、目标ID/类别、几何距离、可见性判定与动作成本；用失败原因与部分进展补足二元成功

  3. Approach

    规范输入/本体→可达成功区域→STOP判定→SR与路径效率；没有新policy表示

  4. Evidence · 原文指定段落
