# Source-backed navigation research trees

The review route `/review/radar-c2-analysis/` now reads a versioned explicit graph.
The initial map preserves the original General goal → Literature tree / Challenge–Insight tree sibling structure. The paper-analysis tree remains independent, with all 59 original questions and their asymmetric five-chapter topology. Map and outline are presentations of the same hierarchy.

## Content boundaries

- The curated graph has 90 core nodes and 18 contextual records, with 139 typed edges and 222 source-located claims. It is a selective reading graph, not a complete field taxonomy.
- Core references currently resolve to 33 unique works, 17 explicitly identified method variants and 74 paper positions. The larger source registry is a bibliographic/source index, not a count of fully read papers.
- The six first-level problem entries are nonexclusive editorial reading choices. They are not a chronology or assertions of invention.
- Pipeline membership, improvements, supported method reuse, challenge decomposition and insight support are explicit. Benchmarks, modality or memory conditions never acquire a parent by keyword matching.
- First-work priority remains unresolved unless an exact scoped assertion is present. A reading anchor is not a first-work badge.
- The old 39 identities, 19 protocol entries, claims and Stage states remain unchanged. Their historical projection and deep links remain accessible.
- PONI adds 22 source-scoped answers to the original 59-question template. This is selected-section partial analysis, not complete Stage 1–3, code reading or reproduction. Missing questions are not claims that the paper lacks the content.
- Canonical identity never merges source versions or reading scopes. Research-origin links cannot silently acquire old HarnessVLN v3 or NavHarness manuscript answers. Older fixed-version analyses have explicit separate links.

## Evidence and reference fidelity

The four user-provided reference images are preserved byte-for-byte. The complete reference projection has 60 example nodes and 59 template nodes, including the outline-only PhotoMat citation, fuller Monte Carlo note and complete Limitation annotation. Historical embedded images and source bundles remain separately protected. The Limitation note is source material, not an instruction to conceal scientific weaknesses.

The public allowlist includes only UI assets, the reviewed graph, source metadata, authored summaries and authorized reference images. Fetched full-paper text, private extraction snapshots and unrelated research notes are not published. New research pins are separate from unchanged historical scientific hashes.
