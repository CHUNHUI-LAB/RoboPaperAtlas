# Atlas 星图

首页星图是原创程序化视觉：细小的白、薄荷绿与浅紫色光点构成有深度的旋臂结构。点位、亮度、旋臂和几何布局均为抽象设计，不表示论文、引用边、实际嵌入向量、论文相似度或实测结果。四个文字入口及书目数量来自公开目录，链接到相应主题筛选。

- `assets/hero-atlas.js` 使用固定种子构成 3,710 个点；动画为缓慢的体积旋转和微弱明暗变化，没有鼠标斥力或页面级星空
- Canvas 2D 使用约 30 FPS 的绘制上限、最高 2× 像素比；无运行时依赖、网络请求或外部素材
- 手动暂停在离屏、页面隐藏以及模式切换后保留；离屏/隐藏时停止帧循环
- 手机和减少动态效果模式显示稳定静态构图；JavaScript 或 Canvas 不可用时保留预生成 SVG 和真实主题链接
- `scripts/render_atlas.cjs` 使用相同点位公式确定性生成较轻的静态 SVG；`node scripts/render_atlas.cjs` 可重建
- `node tests/test_hero_atlas.cjs` 检查确定性、边界、静态文件、生命周期、重复切换和无 Canvas 降级；这是 DOM 模型测试，不替代浏览器像素、性能或触摸设备验证

图形为 RoboPaperAtlas 原创，没有使用参考网站的图像、录像帧、字体文件或三维素材。
